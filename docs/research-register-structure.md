# Research register structure

This public note describes the organization of the private research register. It contains no project records, names of collaborators, financial information, manuscript decisions, unpublished ideas, or internal folder links.

| Field group | Fields recorded |
| --- | --- |
| Identification | Project ID, title, acronym, research domain |
| Origin and responsibility | Idea date, originators, project lead, team members |
| Research plan | Objective, status, research type |
| Collaboration and resources | Institutions, funding source, datasets, tools, models |
| Ethics and schedule | Ethics-review requirement, start date, estimated completion date |
| Publication lifecycle | Target publication, submission, review feedback, revision, decision, publication date, DOI/link |
| Record management | Notes and folder reference |

The structure supports responsibility assignment and tracking of research through publication. The field list does not establish the accuracy, completeness, approval, or financial performance of individual records. The populated workbook is retained privately.
